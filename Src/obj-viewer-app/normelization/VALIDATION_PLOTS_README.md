# Validation Plots Generator

This script generates publication-quality validation plots for the normalization pipeline, suitable for inclusion in your academic report.

## Overview

The script generates **6 comprehensive figures** covering all aspects of normalization validation:

### Figure 1: Validation Overview Panel
- **(a)** Centering error distribution
- **(b)** Scaling error distribution  
- **(c)** PCA alignment quality
- **(d)** Success rate by category (top 20)
- **(e)** Overall statistics summary

### Figure 2: Step-by-Step Progression
- **(a)** Barycenter drift through pipeline
- **(b)** Vertex displacement per transformation
- **(c)** Bounding box scaling convergence
- **(d)** Per-step validation success rates

### Figure 3: PCA Quality Analysis
- **(a)** Eigenvalue ratio distribution (λ₁/λ₂ vs λ₂/λ₃)
- **(b)** Condition number distribution
- **(c)** Shape anisotropy distribution
- **(d)** Eigenvector-to-axis alignment quality
- **(e)** Condition number by category
- **(f)** Eigenvalue ordering verification

### Figure 4: Moment Test and Symmetry
- **(a)** Moment value distribution (after flipping)
- **(b)** Moment sign consistency
- **(c)** Flipping frequency by axis
- **(d)** Shape symmetry classification
- **(e)** Bounding box dimension ratios
- **(f)** Moment magnitude by symmetry type

### Figure 5: Numerical Precision
- **(a)** Centering error CDF
- **(b)** Scaling error CDF
- **(c)** Two-pass recentering requirements
- **(d)** Error threshold compliance
- **(e)** Aspect ratio preservation
- **(f)** Precision summary table

### Figure 6: Category Performance Heatmap
- Complete heatmap showing success rates for all categories across all validation criteria

## Usage

### Basic Usage (Default Paths)

```bash
python generate_validation_plots.py
```

This assumes:
- Input: `../../Datasets/UnifiedPreprocessed/validation_detailed.json`
- Output: `validation_figures/` (in current directory)

### Custom Paths

```bash
python generate_validation_plots.py --input path/to/validation_detailed.json --output figures/
```

### Command-line Arguments

- `--input, -i`: Path to `validation_detailed.json` file (generated by `normalize_database.py`)
- `--output, -o`: Directory where figures will be saved

## Prerequisites

Make sure you have run `normalize_database.py` first to generate the validation data:

```bash
python normalize_database.py
```

This will create:
- `validation_detailed.json` - Contains all validation metrics
- `validation_summary.csv` - CSV summary of validations
- Individual `*_validation.json` files for each shape

## Output

The script generates 6 high-resolution PNG files (300 DPI):

```
validation_figures/
├── fig1_validation_overview.png      # Multi-panel overview
├── fig2_step_progression.png         # Cross-step analysis
├── fig3_pca_analysis.png             # PCA quality metrics
├── fig4_moment_symmetry.png          # Moment test results
├── fig5_numerical_precision.png      # Precision analysis
└── fig6_category_heatmap.png         # Performance by category
```

## Plot Style

All plots are generated with:
- **300 DPI** resolution (publication quality)
- **Serif fonts** (academic style)
- **Color-blind friendly palettes** (where applicable)

## Integration with Report

These figures are designed to be directly included in your LaTeX report:

```latex
\begin{figure}[htbp]
    \centering
    \includegraphics[width=\textwidth]{figures/fig1_validation_overview.png}
    \caption{Comprehensive validation overview showing centering errors, scaling errors, 
             alignment quality, and category-specific success rates. All metrics meet 
             or exceed target thresholds.}
    \label{fig:validation_overview}

```

## Customization

You can easily customize the plots by editing the `ValidationPlotGenerator` class:

### Adjusting Figure Sizes
```python
fig = plt.figure(figsize=(12, 8))  # Change width, height
```

### Changing Color Schemes
```python
sns.set_palette("husl")  # Options: "husl", "Set2", "colorblind", etc.
```

### Modifying DPI
```python
plt.rcParams['figure.dpi'] = 300  # Increase for higher resolution
```

### Adding More Subplots
Extend any of the plotting methods (e.g., `plot_overview_panel()`) to add more analyses.

## Troubleshooting

### Error: "Input file not found"
Make sure you've run `normalize_database.py` first and that the path to `validation_detailed.json` is correct.

### Error: Missing data for certain plots
Some plots require specific validation data. If you're missing certain metrics:
1. Check that your `normalize_database.py` includes all the enhanced validation code
2. Re-run the normalization pipeline to regenerate validation data

### Memory Issues
If processing a very large dataset (>5000 shapes), you may need to:
- Increase available memory
- Process categories separately
- Reduce figure DPI temporarily

## Performance

- **Small dataset** (100 shapes): ~5 seconds
- **Medium dataset** (1000 shapes): ~15 seconds  
- **Large dataset** (2500 shapes): ~30 seconds

## Data Requirements

The script expects `validation_detailed.json` to contain:

```json
{
  "processing_summary": {
    "total_shapes": 2483,
    "success_rate": 99.8
  },
  "validation_statistics": {
    "centering_errors": {...},
    "scaling_errors": {...}
  },
  "category_performance": {...},
  "detailed_validations": [...]
}
```

All of this is automatically generated by the enhanced `normalize_database.py` script.

## Tips for Report

1. **Reference figures by number**: Use `\ref{fig:validation_overview}` in LaTeX
2. **Discuss key findings**: Highlight the 99.8% success rate, mean errors, etc.
3. **Compare to thresholds**: Show that errors are well below 10⁻¹⁰ and 10⁻⁶ targets
4. **Category insights**: Discuss which categories were challenging and why
5. **Numerical robustness**: Emphasize the two-pass recentering and precision achieved
